# МЕНЕДЖЕР ФОТОСМАЙЛ

Браузерная мини-игра: девушка-менеджер фотосалона ловит напечатанные фотографии,
которые выбрасывают четыре принтера по углам зала.

* Механика — по мотивам классических карманных электронных игр,
  вся графика и персонажи оригинальные и нарисованы кодом (Canvas 2D).
* Чистый JavaScript, без библиотек, без внешних файлов-ассетов.
* Звук — Web Audio API (файлов не нужно).
* Рекорд хранится в `localStorage`.

## Как запустить

1. **Просто открыть файл** `index.html` в браузере (двойной щелчок) — игра работает
   и по `file://`, интернет не нужен.
2. **Одним файлом:** `fotosmile-standalone.html` — тот же код, собранный в один HTML
   (CSS и JS встроены). Удобно переслать или залить куда угодно.
3. **На хостинге:** скопируйте `index.html`, `style.css`, `game.js` в любую папку
   на сервере — этого достаточно, ничего собирать не нужно.
4. **Локальный сервер** (необязательно): `python3 -m http.server` в папке проекта,
   затем открыть `http://localhost:8000/`.

Пересобрать одностраничную версию после правок: `node build.js`.

## Управление

| Действие | Компьютер | Телефон |
|---|---|---|
| Позиция ↖ (левый верхний принтер) | `W` · `↑` · `Q` · Numpad `7` | кнопка ↖, свайп вверх/влево, тап в левую верхнюю четверть |
| Позиция ↗ | `D` · `→` · `E` · Numpad `9` | кнопка ↗, свайп вправо, тап в правую верхнюю четверть |
| Позиция ↙ | `A` · `←` · `Z` · Numpad `1` | кнопка ↙, свайп вниз, тап в левую нижнюю четверть |
| Позиция ↘ | `S` · `↓` · `C` · Numpad `3` | кнопка ↘, тап в правую нижнюю четверть |
| Пауза | `P` · `Esc` · `Пробел` | кнопка ❚❚ |
| Звук | `M` | кнопка динамика |
| Старт / продолжить | `Enter` · `Пробел` | кнопка «НАЧАТЬ СМЕНУ» |

Переключение мгновенное: анимация рук догоняет управление, а не задерживает его.
Раскладка клавиш намеренно повторяет расположение принтеров (W/↑ — верхний левый,
D/→ — верхний правый, A/← — нижний левый, S/↓ — нижний правый), поэтому
правая нижняя позиция дополнительно продублирована клавишами `C` и Numpad `3`.

## Правила

* Менеджер стоит в центре, четыре принтера по углам печатают и «выбрасывают» фото
  в сторону центра.
* Нужная позиция — фото поймано: **+1 очко**, летящая надпись `+1`, искры, довольная реакция.
* Не та позиция — фото падает на пол: **−1 жизнь** из трёх, тряска поля, грустная реакция.
* Три промаха — «Смена окончена!» с результатом, кнопками «Играть снова» и «Главное меню».
* Рекорд сохраняется в `localStorage` и показывается в главном меню и на экране результата.

## Сложность

Сложность считается плавной логистической кривой от числа пойманных фото (0 → 1),
а не линейно. От неё зависят скорость фото, интервалы печати, время предупреждения
принтера и максимальное число фотографий в воздухе одновременно.

| Очки | Ощущение | Скорость фото | Пауза между фото | Предупреждение | Фото в воздухе |
|---|---|---|---|---|---|
| 0–10 | очень спокойно | ~180 px/с | 1.05–1.9 с | 0.65–0.9 с | 1 |
| 10–25 | немного быстрее | ~260 px/с | ~0.9–1.6 с | ~0.55–0.8 с | 1–2 |
| 25–50 | средняя | ~400 px/с | ~0.6–1.1 с | ~0.4–0.6 с | 2 |
| 50–80 | быстро | ~540 px/с | ~0.45–0.8 с | ~0.3–0.45 с | 3 |
| 80–120 | очень быстро | ~630 px/с | ~0.35–0.6 с | ~0.22–0.3 с | 3–4 |
| 120+ | максимум | 700 px/с | 0.27–0.38 с | 0.16–0.22 с | 4 |

**Честность гарантирована алгоритмом:** пока какая-нибудь фотография ближе 150 px
к центру, новые принтеры печатать не начинают, а сменить позицию в этот момент уже
нельзя (появляется подсказка «!»). Замеры на максимальной сложности показывают, что
минимальный интервал между необходимыми переключениями — около 0.23–0.3 с, то есть
человек физически успевает. Заведомо невозможных комбинаций не возникает.

## Эффекты и пасхалки

* Предупреждение принтера: мигает корпус, горит оранжевый «!», появляется пунктирная
  трасса к центру, принтер «гудит» — видно, откуда сейчас прилетит фото.
* Редкие подбадривающие надписи: «Отлично!», «Готово!», «Следующий заказ!», «Супер!»,
  «Клиент доволен!» (не чаще, чем раз в ~5–8 секунд).
* Рубежи: 25 — «Начался час пик!», 50 — «Заказов всё больше!», 100 — «Настоящий профи!».
* 50 фото подряд без ошибок — «Идеальная смена!» и звёздочки вокруг менеджера.
* 100 фото подряд — менеджер на несколько секунд надевает корону.
* Новый рекорд — баннер «НОВЫЙ РЕКОРД! 🎉» и короткая фанфара (первая смена в игре
  тоже считается рекордом).

## Структура проекта

```
fotosmile/
├── index.html                 точка входа (структура страницы)
├── style.css                  оформление: меню, HUD, экраны, адаптив, сенсорные кнопки
├── game.js                    вся игра (см. разделы ниже)
├── build.js                   сборка одностраничной версии
├── fotosmile-standalone.html  автосборка: всё в одном файле (для пересылки/хостинга)
├── README.md
└── tests/
    ├── harness.js             стенд: мок DOM/Canvas/времени, загрузка game.js в Node
    ├── headless-test.js       123 проверки игровой логики без браузера
    ├── browser-test.js        112 проверок в настоящем Chromium (клики, тачи, FPS)
    └── balance-test.js        баланс и честность: виртуальный игрок с задержкой реакции
```

`game.js` разделён на пронумерованные секции:

1. константы и утилиты, 2. кривая сложности, 3. рекорд (`localStorage`),
4. звук (Web Audio), 5. графика (фон-фотозал, принтеры, фотографии, менеджер),
6. состояние игры, 7. появление и движение фотографий, 8. управление персонажем,
9. ловля / очки / жизни / пасхалки, 10. игровой цикл (`requestAnimationFrame`),
11. отрисовка кадра, 12. интерфейс (экраны, HUD, тосты), 13. ввод, 14. запуск.

Производительность: фон рисуется один раз в offscreen-canvas и дальше копируется,
фотографии удаляются сразу после ловли/падения, эффекты ограничены 60 штуками,
обработчики событий навешиваются один раз, DOM не пересоздаётся каждый кадр,
`dt` ограничен сверху, поэтому после сворачивания вкладки игра не «телепортируется».

## Тесты

```bash
node tests/headless-test.js   # логика: старт, отсчёт, все принтеры, ловля, жизни, Game Over,
                              # перезапуск, пауза, звук, сложность, честность спавна, пасхалки
node tests/balance-test.js    # баланс: виртуальные игроки с реакцией 0/150/250/420 мс
```

Тесты в реальном браузере требуют Chromium и `playwright-core`:

```bash
npm i playwright-core && npx playwright-core install chromium
node tests/browser-test.js    # клики, клавиатура, тач/свайпы, FPS, Web Audio, адаптив,
                              # localStorage, регресс паузы после отсчёта
```

Текущий статус: **123 + 10 + 112 = 245 проверок, все проходят.**

## Заметки

* Игра работает офлайн, кроме Web Audio (он встроен в браузер) — внешних запросов нет.
* Иконки интерфейса сделаны инлайн-SVG, а не эмодзи: эмодзи-шрифты есть не во всех
  системах, а SVG выглядит одинаково всюду.
* Если браузер блокирует `localStorage` (приватный режим, `file://` в некоторых
  сборках), игра продолжит работать — рекорд просто не сохранится.
* Уход со вкладки или потеря фокуса автоматически ставит паузу.
